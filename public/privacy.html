DITUNE

Kebijakan Privasi

Terakhir diperbarui: 12 November 2026 • Dikelola oleh Dijumper Web

DITUNE adalah aplikasi web pemutar musik pribadi (Progressive Web App) yang terintegrasi langsung dengan akun Google Drive Anda. Kebijakan Privasi ini menjelaskan bagaimana aplikasi mengakses, menggunakan, dan menyimpan data saat Anda menggunakan DITUNE.

1. Arsitektur 100% Client-Side

DITUNE berjalan sepenuhnya di sisi peramban (client-side) pada perangkat Anda. Pengembang tidak mengoperasikan server backend untuk mengumpulkan, menyimpan, memindai, atau mengirimkan berkas audio, daftar pustaka lagu, maupun token otorisasi Google Anda.

2. Akses Data Google Drive (Scope drive.file)

DITUNE menggunakan Google Identity Services dan Google Drive API hanya dengan izin minimal https://www.googleapis.com/auth/drive.file. Dengan izin ini:

  • Aplikasi hanya dapat mengakses folder DITUNE Music beserta berkas audio yang diunggah langsung melalui DITUNE.
  • Aplikasi juga hanya dapat mengakses berkas audio lain yang Anda pilih secara eksplisit melalui dialog resmi Google Picker.
  • DITUNE tidak memiliki izin untuk melihat, mengubah, atau menghapus dokumen maupun berkas pribadi lain di Google Drive Anda di luar lingkup tersebut.

3. Penyimpanan Lokal di Perangkat Anda

  • IndexedDB: Digunakan untuk menyimpan metadata lagu (judul, artis, album, durasi), sampul album, daftar lagu yang disembunyikan, serta cache berkas audio agar dapat diputar secara offline.
  • localStorage / sessionStorage: Digunakan untuk menyimpan token sesi akses sementara OAuth Google (berlaku sekitar 1 jam) beserta jenis scope aktif agar Anda tidak perlu masuk berulang kali selama sesi masih berlaku.

4. Kepatuhan Kebijakan Data Pengguna Google

Penggunaan dan pemindahan informasi yang diterima dari Google API oleh DITUNE mematuhi Google API Services User Data Policy, termasuk persyaratan Limited Use. Data Anda tidak digunakan untuk periklanan, tidak dijual, dan tidak dibagikan kepada pihak ketiga mana pun.

5. Menghapus Data & Mencabut Izin

  • Anda dapat menghapus seluruh cache audio maupun daftar pustaka lokal kapan saja melalui menu Pengaturan → Kosongkan Perpustakaan atau membersihkan data situs di peramban.
  • Anda dapat mencabut izin akses Google Drive milik DITUNE kapan saja melalui halaman Izin Akun Google.

6. Kontak

Jika Anda memiliki pertanyaan terkait kebijakan privasi ini, silakan hubungi pengembang di novianasproject@gmail.com.
